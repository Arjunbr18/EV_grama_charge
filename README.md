# EV Grama Charge

## Smart Rural EV Charging Management System

EV Grama Charge is an Android-based mobile application developed to improve Electric Vehicle (EV) charging accessibility in rural and semi-urban areas. The platform helps EV users locate charging stations, view charger details, securely access charging facilities using QR verification, and receive smart charging recommendations.

The project focuses on promoting sustainable transportation and improving EV infrastructure in underserved regions through a simple, scalable, and user-friendly solution.

---

# Problem Statement

Many rural and village areas still face challenges in EV adoption because of limited charging infrastructure and lack of digital charging management systems. EV users often struggle with:

* Finding nearby charging stations
* Checking charger availability
* Accessing charging stations securely
* Understanding charger compatibility
* Managing charging information efficiently

EV Grama Charge solves these problems by providing a centralized smart EV charging platform.

# System Workflow

1. User opens the EV Grama Charge application.
2. The application retrieves charging station data from Firebase.
3. Users can search and view nearby charging stations.
4. Smart recommendation logic suggests suitable chargers.
5. QR code verification is used for charger access.
6. Charging information updates dynamically in real time.

# Installation and Setup

## Prerequisites

Make sure the following software is installed:

* Android Studio
* Java JDK
* Firebase Account
* Android Emulator or Physical Device

---

## Clone the Repository

```bash
git clone https://github.com/Arjunbr18/EV_grama_charge.git
```

---

## Open in Android Studio

1. Open Android Studio
2. Click on Open Existing Project
3. Select the cloned project folder

---

## Firebase Setup

1. Create a Firebase project
2. Enable Firebase Realtime Database
3. Enable Firebase Authentication
4. Download the google-services.json file
5. Place the file inside the app/ directory

---

## Run the Project

1. Sync Gradle files
2. Connect Android device or emulator
3. Click Run in Android Studio
